# ADR-001: SQLite через rusqlite (bundled) вместо tauri-plugin-sql

Статус: принят. Дата: 2026-10-07. Контекст спринта: S1.

## Решение
БД обслуживается из Rust: `rusqlite` + feature `bundled` (статическая линковка SQLite), версионируемые SQL-миграции в `src-tauri/migrations`, WAL, шифрование значений (AES-256-GCM) на уровне приложения перед записью.

## Обоснование
1. ТЗ требует шифрование содержимого буфера на уровне приложения с ключом DPAPI/Credential Manager — плагин sql этого не даёт; криптоконтейнер (`content_enc` BLOB) должен формироваться в том же модуле, что и фильтры секретов (M6).
2. Миграции и индексы (`content_hash`, `created_at`, `prompt_hash`, `launch_count`) контролируются нами без зависимости от API плагина.
3. Единый слой доступа = тестируемость ядра на Linux CI (без WebView2): unit-тесты фильтрации/дедупликации гоняются без Windows.
4. bundled SQLite убирает нативную зависимость libsqlite3 в CI.

## Последствия
- Команды `clipboard_*`, `settings_*` реализуются как custom #[tauri::command] (уже в контракте ТЗ §5.2), capability фронтенда к sql не требуется — даже безопаснее.
- Отклонение от строки «SQLite через tauri-plugin-sql» ТЗ §4 зафиксировано здесь; функциональные требования не меняются.
