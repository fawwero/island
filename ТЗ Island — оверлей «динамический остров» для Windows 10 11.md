# Техническое задание: Island

Оверлей «динамический остров» для Windows 11 · Версия ТЗ 1.1 · Основание: технический анализ демо-ролика

**Условные обозначения:** MoSCoW — Must / Should / Could / Won't (для MVP). «Требует уточнения» (ТУ) — данных в анализе недостаточно.

## 1. Общее описание продукта

| Параметр                              | Значение                                                                                                                                                                                                                                                                                   |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Назначение                            | Единый плавающий элемент интерфейса в верхней части экрана: уведомления, медиа, буфер обмена, OCR/скриншоты, полка файлов, лончер, ИИ-чат                                                                                                                                                  |
| Ключевая идея                         | Объединить утилиты производительности в «жидкий» остров, реагирующий на курсор и системные события                                                                                                                                                                                         |
| Целевая аудитория                     | Пользователи Windows 11, ценители UX/UI, гики, активные пользователи утилит и ИИ-инструментов (личное использование)                                                                                                                                                                       |
| Платформы                             | **Windows 11** (минимальная сборка 22621, версия 22H2), только x64. Windows 10 и ARM64 не поддерживаются (решение владельца проекта)                                                                                                                                                       |
| Распространение                       | **Бесплатно**, для локального использования. Freemium/Subscription отклонены: без подписок, платежей, лицензирования и платных зависимостей. Публикация: открытый репозиторий GitHub, GitHub Releases (portable ZIP и NSIS-установщик, сборка в GitHub Actions); лицензия репозитория — ТУ |
| Разработка                            | Владелец проекта + Claude (ИИ-ассистент); бюджет — 0                                                                                                                                                                                                                                       |
| Отличие от Dynamic Island (macOS/iOS) | Нет аппаратной «выемки» — остров рисуется программно поверх окон, по одному независимому острову на каждый монитор; интеграции — через Windows-API (SMTC, WinRT OCR, Core Audio, глобальные хоткеи); встроенные лончер, OCR, полка файлов и ИИ-чат                                         |

**Вне рамок ТЗ (Won't):** подписка, платежи и лицензирование; Windows 10 и ARM64; ноутбуки с вырезом и поддержка жестов (только стандартные ноутбуки); расширение для браузера (точный процент загрузок); структура страницы настроек определяется в ходе разработки (требование к полноте — M11). Движок OCR принят по анализу: Windows.Media.Ocr.

### 2.2. Детализация модулей

#### M1. Оверлей острова

| Аспект           | Описание                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Вход             | Положение курсора (глобально); события аудиосессии; события модулей M6–M8; настройки                                                                                                                                                                                                                                                                                                                     |
| Поведение        | Состояния: _idle_ → _hover_ (расширение при наведении или «притяжении» к курсору) → _expanded_ (панель модуля) → _activity_ (индикаторы). Окно: без рамки, прозрачное, always-on-top, скрыто из панели задач и Alt+Tab. Click-through (`WS_EX_TRANSPARENT`/`WS_EX_NOACTIVATE`) переключается динамически: сквозное вне фигуры острова, интерактивное внутри                                              |
| Мультимонитор    | На каждом мониторе — собственный остров (отдельное окно и состояние); острова между собой не связаны и контент не дублируют. Системные события (медиа, загрузка, запись) показываются на одном острове — на мониторе с активным (фокусным) окном, при его отсутствии — на мониторе с курсором. Подключение/отключение мониторов и смена DPI (`WM_DISPLAYCHANGE`, `WM_DPICHANGED`) обрабатываются на лету |
| Выход            | Анимация 60 FPS; события в UI активного модуля                                                                                                                                                                                                                                                                                                                                                           |
| Граничные случаи | Перекрытие заголовков окон Windows; полноэкранные приложения (автоскрытие, раздел 7); блокировка/разблокировка сессии; ноутбуки — только стандартные (без выреза и обработки жестов); тачскрин и жесты вне рамок; таскбар вверху экрана — ТУ                                                                                                                                                             |

#### M5. Полка файлов

| Аспект           | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Вход             | Drag & Drop файлов и папок на остров (OLE `IDropTarget`)                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Поведение        | Остров раскрывается при перетаскивании над ним; сохраняется ссылка (путь + метаданные), файл не копируется — размер файла не ограничен. Повторный drag из полки в другое окно; передача в лончер и чат ИИ. Срок хранения — до закрытия или перезапуска приложения: при каждом старте Rust-бэкенда таблица `shelf_files` очищается (файлы на диске не затрагиваются). Идентификатор сессии (GUID) хранится только в памяти; при автозапуске с Windows полка очищается и после перезагрузки ПК |
| Выход            | Записи в `shelf_files`; файл в целевом приложении                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Граничные случаи | Файл удалён или перемещён — статус «недоступен»; сетевые пути и съёмные диски; папки; максимум элементов — 100 по умолчанию (настраивается). Лимит 10 ГБ применяется только к кэшу копий (миниатюры, изображения буфера), не к файлам на полке. Для ИИ действуют лимиты Gemini API, а не полки. Список теряется при перезапуске или сбое приложения — принято владельцем (вместо volatile-ключа реестра)                                                                                     |

#### M6. История буфера обмена

| Аспект           | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Вход             | События `WM_CLIPBOARDUPDATE` (`AddClipboardFormatListener`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Поведение        | Сохраняются текст, URL, изображения (`CF_DIB`/PNG → PNG-файл в `%LOCALAPPDATA%\Island\cache\clipboard`, шифруется AES-256-GCM) и файлы (`CF_HDROP` — только список путей, содержимое не копируется, размер файлов не ограничен). Дедупликация; клик по записи — запись в буфер и эмуляция вставки (`SendInput` Ctrl+V; изображение и файлы вставляются в исходном формате); закрепление записей. Фильтры: пропуск при форматах `ExcludeClipboardContentFromMonitorProcessing` / `CanIncludeInClipboardHistory = 0`, чёрный список процессов-источников, эвристика секретов (токены, ключи) |
| Выход            | Записи в `clipboard_history`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Граничные случаи | Большой текст (>1 МБ) — обрезать или не сохранять; изображение больше лимита на элемент (по умолчанию 20 МБ на закодированный PNG, настраивается) не сохраняется; суммарный кэш изображений ≤10 ГБ (настраивается), при превышении удаляются старые незакреплённые; исчезнувший файл по пути — запись помечается; автоочистка по сроку и числу записей; пауза записи из трея                                                                                                                                                                                                               |

#### M7. Индикаторы статуса

| Аспект           | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Запись экрана и микрофон — системные записи приватности Windows 11 (`HKCU\Software\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentStore`, ключи `graphicsCaptureProgrammatic` и `microphone`; признак активности — `LastUsedTimeStop = 0`; подписка `RegNotifyChangeKeyValue`; флаг LastUsedTimeStop = 0 подтверждён владельцем для Windows 11; резерв — Core Audio); для микрофона дополнительно сессии захвата Core Audio (`IAudioSessionManager2`). Запись экрана и микрофон: индикатор активности с именем процесса-источника. Диктовка: включается хоткеем Win+Alt+V (запасной вариант Ctrl+Alt+D, если регистрация не удалась; настраивается); режимы Hold-to-Talk (отпускание клавиш определяется опросом GetAsyncKeyState только на время диктовки) и Toggle (одно нажатие) выбираются в настройках; на острове — пульсирующий индикатор микрофона и волновая форма, по завершении фразы ≈0,5 с показывается «Распознавание…»; распознавание локально через `whisper-rs` (whisper.cpp, мультиязычная модель GGML base ≈150 МБ или small ≈470 МБ; скачивается при первом включении; RU/EN); модель в памяти только на время диктовки; текст вставляется в активное поле вводом через `SendInput` (Unicode-ввод; буфер обмена не используется). Компактные иконки в _idle_, детали в _expanded_ |
| Выход            | События `activity:update`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Граничные случаи | Несколько одновременных активностей (приоритет и ротация); отмена загрузки (временный файл исчез); браузер не создаёт временный файл; ключи реестра приватности недокументированы (запасной вариант: Core Audio для микрофона и список известных рекордеров — Could); нет разрешения на микрофон; нагрузка CPU при длинной диктовке (ограничить длину фрагментов, использовать VAD)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

### 5.1. Слои


Миграции — через версионируемые SQL-файлы; `PRAGMA journal_mode=WAL`; индексы по `content_hash`, `created_at`, `prompt_hash`, `launch_count`.

### 5.5. Потоки данных ключевых сценариев

**Хоткей → лончер**

1. `RegisterHotKey(Alt+Space)` → сообщение `WM_HOTKEY` в потоке-обработчике.
2. Rust показывает окно лончера (`launcher:visibility = true`), даёт фокус полю ввода.
3. UI вводит текст → `launcher_search` (дебаунс 30 мс).
4. Rust: запрос к `app_index` + парсер выражений/единиц → `Result[]`.
5. Enter → `launcher_run` → `ShellExecuteEx`/активация UWP → окно скрывается, `launch_count++`.

**Drag & Drop → полка**

1. Пользователь тянет файл над островом → OLE `IDropTarget::DragEnter` → `overlay_set_state(expanded)`, `overlay_set_interactive(true)`.
2. `Drop` → список путей → `shelf_add` → запись в `shelf_files`.
3. Событие `shelf:changed` → UI показывает карточку файла.
4. Повторный drag из острова → `shelf_start_drag` (`DoDragDrop` с `CF_HDROP`); при отсутствии файла — статус `missing`.

**Скриншот → OCR → буфер**

1. Хоткей/кнопка → `capture_start(ocr)` → полноэкранное окно-селектор на всех мониторах.
2. Пользователь выделяет область → Rust захватывает регион (Windows.Graphics.Capture / DXGI, с учётом DPI).
3. `SoftwareBitmap` → `OcrEngine::TryCreateFromUserProfileLanguages` → текст.
4. Текст → системный буфер; запись в `clipboard_history` помечается как OCR-источник (подчиняется фильтрам M6).
5. `capture:result` → остров показывает «Скопировано» и скрывается через 2 с.

## 6. Этапы разработки

Спринт = 2 недели. Объём работ определён анализом: MVP — референс 2–2,5 месяца при команде из 2 человек (Rust/WinAPI + Frontend/UI); полная версия — референс 4–6 месяцев при 3–4 человеках. Фактический исполнитель — владелец проекта + Claude: календарные сроки пересчитываются после выбора недельной нагрузки (ТУ), состав и порядок спринтов сохраняются. Платформа — только Windows 11.

Ответы и финализация открытых вопросов (Раздел 9.3)

1.  Лицензия открытого репозитория

    Решение: MIT License (или пермиссивная дуальная MIT / Apache-2.0).

    Обоснование: Совместима с экосистемой Rust (большинство крейтов используют данную связку), не накладывает коммерческих ограничений и позволяет сообществу свободно использовать наработки, что соответствует духу бессрочно бесплатного open-source проекта без монетизации.

2.  Конкретные наборы спрайтов и проверка лицензий

    Решение: Формирование директории /assets/residents/ с явным файлом LICENSES.md.

    Источники:

        Pixel Adventure 1 & 2 by Pixel Frog (Public Domain / CC0).

        Free Cute Domestic Animals Sprites by CraftPix.net (Free with Attribution).

        Pipoya Free Pixel Arts (Free for Commercial/Non-commercial, Attribution optional).

    Правило: При сборке через GitHub Actions линтер проверяет наличие соответствия каждого спрайт-листа манифесту LICENSES.md.

3.  Глобальный хоткей захвата скриншота / OCR

    Решение: Win + Shift + S — стандартное системное сочетание для OCR/Захвата, ЛИБО базовое дефолтное Ctrl + Alt + X (для OCR) и Ctrl + Alt + S (для скриншота).

    Перехват: Поскольку Win + Shift + S занят системным Snipping Tool, Island регистрирует Ctrl + Alt + X по умолчанию, предоставляя возможность переназначить его в настройках (M11) через tauri-plugin-global-shortcut.

4.  Подтверждение сброса Полки файлов при перезапуске приложения

    Подтверждено: Да, полностью приемлемо.

    Полка файлов задумывается как буфер временного оперативного обмена («верстак» для текущей рабочей сессии). Хранение исключительно в RAM (через GUID сессии) упрощает архитектуру, исключает проблему битых ссылок при длительном хранении и отвечает требованиям приватности.

5.  Подтверждение автоподбора модели Gemini из списка API

    Подтверждено: Да, это наиболее устойчивое решение.

    При старте сессии Rust-бэкенд выполняет запрос GET [https://generativelanguage.googleapis.com/v1beta/models?key=API_KEY](https://generativelanguage.googleapis.com/v1beta/models?key=API_KEY).

    Алгоритм фильтрует модели по маске _flash_, отсеивает депрекейтнутые варианты и выбирает актуальную стабильную версию. В случае ответа 429 или ошибки сети приложение автоматически переключается на запасное значение из локального конфига (gemini-2.5-flash).

6.  Расположение и структура страницы настроек (M11)

    Решение: Модальное окно поверх активного острова / отдельная таб-панель во фронтенде.

    Размещение: Сайдбар слева с категориями (Общие, Мониторы, Хоткеи, ИИ, Буфер обмена, Полка, Индикаторы, Питание, Экспорт/Импорт) и адаптивная область контента справа. Компоненты UI разрабатываются на базе Tailwind CSS + Motion в спринте S5.
